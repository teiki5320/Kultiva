🌱 Politique de confidentialité

Dernière mise à jour : 24 août 2026

Kultiva est une application de jardinage développée par Jean Perraudeau (ci-après « nous »). Cette politique explique quelles données nous collectons, pourquoi, et comment nous les protégeons.

1. Données collectées

  • Compte utilisateur — adresse e-mail, nom affiché, identifiant OAuth (Google ou Apple). Collectées lors de l'inscription pour permettre la synchronisation cloud.
  • Données de jardinage — plantations, arrosages, récoltes, badges débloqués, préférences (région, thème, notifications). Stockées localement sur l'appareil et synchronisées sur nos serveurs si tu actives la synchronisation cloud.
  • Photos — photos de plants prises avec la caméra ou importées depuis la galerie. Stockées localement et uploadées dans le cloud si la synchronisation est active.
  • Localisation — position GPS utilisée uniquement pour afficher la météo locale et détecter ta région (France / Afrique de l'Ouest). Jamais stockée sur nos serveurs. Si tu refuses l'accès, Paris est utilisé par défaut.
  • Données de la créature Tamassi — XP, niveau, nom, variante choisie. Synchronisées si le compte cloud est actif.
  • Photos de tes plants et de tes défis — stockées sur ton appareil. Si le compte cloud est actif, elles sont sauvegardées dans ton espace privé, accessible à toi seul. Elles ne sont jamais publiées ni montrées à d'autres utilisateurs.

2. Pourquoi nous collectons ces données

  • Faire fonctionner l'application (calendrier, météo, arrosage).
  • Synchroniser tes données entre tes appareils (facultatif).
  • Afficher le classement Tamassi (XP publique).

Nous ne vendons jamais tes données. Nous n'utilisons pas tes données à des fins publicitaires.

3. Stockage et sécurité

Les données cloud sont hébergées sur Supabase (infrastructure AWS, région Europe — Francfort). L'accès aux données est protégé par :

  • Authentification OAuth2 (Google / Apple) ou e-mail + mot de passe.
  • Row Level Security (RLS) : chaque utilisateur ne peut accéder qu'à ses propres données.
  • Chiffrement en transit (HTTPS/TLS).

Les données locales sont stockées sur ton appareil dans le stockage privé de l'application (SharedPreferences et dossier documents).

4. Partage des données

Nous ne partageons tes données avec aucun tiers, sauf :

  • Supabase — hébergeur cloud (sous-traitant technique).
  • Open-Meteo — service météo gratuit. Seules les coordonnées GPS sont transmises pour obtenir les prévisions. Aucun compte utilisateur n'est partagé.
  • Google / Apple — uniquement pour l'authentification OAuth. Nous recevons ton e-mail et ton nom, rien d'autre.
  • Sentry — rapport d'erreurs technique (crash de l'application). Reçoit des informations techniques anonymisées sur l'appareil et l'erreur, jamais tes données de jardinage ni tes photos.

5. Durée de conservation

  • Données locales : tant que l'application est installée.
  • Données cloud : tant que ton compte existe. Si tu supprimes ton compte, toutes tes données sont effacées sous 30 jours.

6. Tes droits (RGPD)

Tu as le droit de :

  • Accéder à tes données — elles sont toutes visibles dans l'application.
  • Rectifier tes données — modifie ton profil ou tes plantations directement dans l'app.
  • Supprimer ton compte et toutes tes données — dans Paramètres → Supprimer mon compte.
  • Exporter tes données — contacte-nous par e-mail.
  • T'opposer au traitement — désactive la synchronisation cloud dans les paramètres pour utiliser l'app en mode 100 % local.

7. Mineurs

Kultiva est conçue pour être utilisée en famille. Les enfants de moins de 16 ans doivent obtenir le consentement d'un parent ou tuteur avant de créer un compte. Les données de jardinage restent stockées sur l'appareil ; la synchronisation cloud peut être désactivée à tout moment dans les paramètres.

8. Cookies et trackers

L'application mobile n'utilise aucun cookie, aucun tracker publicitaire, aucun outil d'analytics. Aucune donnée de navigation n'est collectée.

9. Modifications

Cette politique peut être mise à jour. En cas de changement significatif, une notification sera affichée dans l'application. La date de mise à jour en haut de cette page fait référence.
